首次双击角色文件夹中的「ControlPanel/OpenMenu.cmd」启用后台模型监测。之后登录 Windows 时自动恢复监测，Live2DViewerEX 加载角色时自动启动对应控制台。每个角色的页面、预览和菜单均包含在自己的目录中。

腿部菜单使用半透明圆角浮层，使用随角色提供的圆体。菜单以角色身体中线居中定位。第一行「打开面板」进入完整页面。
面板后台运行时，角色触发区会拦住点击，避免点击到后面的桌面图标或窗口，拖动仍可移动角色。菜单打开时暂停身体互动，关闭后恢复。恢复待机会同时取消尚未处理的身体点击。

动作、表情、衣装、语音通过标签切换。点击条目即可使用，点击爱心只收藏。
语音区播放设置右侧的音符加号可添加音频和字幕。语音条目旁的垃圾桶会一并删除音频和字幕。
新增语音保存在当前角色的 assets/voices 内，可收藏及循环播放。更新桌面语音库时角色会短暂重载。
动作、语音、换装均可单独开启循环。「只看收藏」同时决定列表和循环范围，开启时只循环❤收藏，关闭时循环全部；搜索仅筛选列表。
点击「随机播放」或「按列表顺序」切换循环顺序，各类内容分别记住顺序、范围和间隔。
动作和语音的间隔从当前内容播放完成后计算。换装间隔是每套衣装的最短停留时间。
三种循环可同时开启。到换装时间时会等待当前动作和语音播放完成，再换装并恢复循环。
「恢复待机」停止全部循环、动作和语音，清除表情与保持状态，保留当前衣装。

循环和桌面浮层由角色面板后台统一执行。浏览器关闭后，后台程序会继续运行。
加载角色后自动连接对应模型位。每个目录副本使用独立连接和自动分配的本地端口，同一目录的多个页面共享状态。打开面板会接管当前已加载的模型。
衣装缩略图首次逐一生成并缓存。桌面换装会同步页面，连接中断后自动尝试恢复。
衣装与语音收藏在角色内共享，动作与表情收藏按衣装保存。互动仅❤开关单独控制身体点击。

角色文件夹可以整体移动，ControlPanel 与 assets 文件夹需一同保留。
Windows 入口使用随附的 ControlPanel.exe，无需另装 Python。
开发者可使用 Python 3.10 或更高版本运行 server.py。
个人收藏、设置和缩略图保存在ControlPanel/.local 内，该目录已设置为 Git 忽略。
