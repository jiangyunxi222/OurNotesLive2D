# A子

OurNotes 创意工坊版，包含 1 套衣装。

## 区域触发

头部切换表情，脸部播放语音，上身与左右手臂播放动作，腰部换装，下身打开菜单。

## 菜单

循环动作、循环语音和循环换装可同时开启。动作结束后等待 12 秒，语音结束后等待 2.5 秒，换装间隔 15 秒。换装等待当前动作和语音结束。

恢复待机停止循环、动作和语音，清除表情，保留当前衣装。
